CORRECCIÓN DE PARPADEO Y RECARGA CONTINUA

Se retiró el Service Worker anterior, que podía tomar el control repetidamente durante Live Server y provocar recargas o destellos.
También se eliminó la transición experimental entre documentos y se corrigió el ciclo de redirección entre login, inicio y validación de perfil.

INSTALACIÓN
1. Sustituye la carpeta del CRM por esta versión.
2. Inicia Live Server desde la carpeta raíz del CRM.
3. Abre una sola vez: http://127.0.0.1:5500/limpiar-cache.html
   Ajusta el puerto si Live Server usa otro.
4. La página retirará Service Workers y cachés antiguas y abrirá login.html.
5. Pulsa Ctrl + F5 una vez.

Si el navegador conserva la versión anterior:
- DevTools > Application > Service Workers > Unregister.
- Application > Storage > Clear site data.
- Cierra todas las pestañas del CRM y vuelve a abrir Live Server.

No es necesario ejecutar SQL.
