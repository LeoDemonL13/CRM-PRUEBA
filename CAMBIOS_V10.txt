LIMPIEZA DE DATOS DE PRUEBA EN ALMACÉN
- Historial de movimientos: Administrador/Jefe de almacén pueden eliminar una operación de prueba desde el propio historial. Si el movimiento pertenece a un folio con varios materiales, se elimina el grupo completo.
- La eliminación del historial de movimientos NO recalcula existencias automáticamente. Esto se muestra como advertencia para evitar alterar el stock de forma silenciosa. Antes de iniciar operación real debe cargarse/validarse el inventario real.
- Órdenes de compra: la eliminación de prueba usa ahora una función segura del SQL maestro y también retira el PDF del bucket cuando exista.
- Proyectos: la eliminación de prueba retira plan de materiales, materiales no listados, reservas y relaciones del proyecto. Si todavía tiene movimientos, se bloquea hasta que esos movimientos se limpien primero.
- Solicitudes de material: cada solicitud tiene opción Eliminar para Administrador/Jefe de almacén. También limpia reajustes/notificaciones relacionados.
- Reajustes de material: se pueden eliminar individualmente como registros de prueba.
- Herramientas: la eliminación de prueba puede retirar catálogo, unidades, asignaciones, historial y relaciones con proyectos, con confirmación reforzada.
- Unidades de herramientas: cada unidad puede eliminarse junto con sus asignaciones e historial relacionados.
- Asignaciones de herramientas: cada asignación puede eliminarse como dato de prueba; si estaba activa, la unidad vuelve a estado Disponible.
- Historial de herramientas: cada evento puede eliminarse individualmente por Administrador/Jefe de almacén.
- Vehículos: la eliminación de prueba puede retirar vehículo, viajes y gastos relacionados.
- Se mantienen confirmaciones dobles en operaciones destructivas para reducir eliminaciones accidentales.

SQL
- Se conserva un solo archivo: SQL_MAESTRO_CRM.sql.
- Se añadieron RPC seguras SECURITY DEFINER para limpieza de pruebas, limitadas a Administrador y Jefe de almacén.
