RH · Comunicaciones y automatización

Remitentes, canales y envío de informativas

Define qué número y correo representa a RH. Los tokens y claves privadas se mantienen en Supabase Edge Function Secrets, nunca en el navegador.

WhatsApp de RH

Manual abre WhatsApp; Cloud API permite automatizar.

Correo de RH

Manual abre el cliente de correo; Resend permite envío automático con PDF adjunto.

Automatización semanal

El checador físico concilia el miércoles. El envío de informativas queda programado para el jueves a las 21:00 hora local.

Diagnóstico de comunicaciones

Comprueba WhatsApp, correo, remitentes y secretos sin enviar ningún comprobante.

Secretos que no se guardan aquí

Para automático, configura en Supabase Secrets: RH_WHATSAPP_TOKEN (o WHATSAPP_TOKEN) y RH_RESEND_API_KEY (o RESEND_API_KEY). El Phone Number ID puede capturarse arriba o dejarse como secreto de respaldo. Para Cron usa CRON_SHARED_SECRET. Los campos visibles de esta ventana solo contienen datos no secretos del remitente.

Integración oficial

Configurar canales para nómina

WhatsApp y correo automático se ejecutan desde Edge Functions; las claves privadas permanecen en Supabase.

1. Meta

Registra el número en WhatsApp Business Platform, obtén Phone Number ID y token, y crea la plantilla nomina_informativa_pago con encabezado Documento y tres variables.

2. Supabase

Despliega la Edge Function rh-enviar-nomina-whatsapp y crea sus secretos. La pantalla debe pasar de “Función no disponible” a “Lista”.

3. Diagnóstico

Usa Configuración → Diagnosticar. Revisa número verificado, plantilla aprobada, encabezado PDF y secretos.

4. Automatización

Programa Supabase Cron. El CRM conserva martes-lunes y la función solo procesa el jueves a la hora configurada.
