Correo y WhatsApp de Compras

Define los remitentes visibles y datos operativos de cada canal. Las claves privadas permanecen en Supabase Secrets.

Correo de Compras

Puedes abrir tu cliente de correo o enviar automáticamente mediante Resend.

En automático, CO_RESEND_API_KEY (o RESEND_API_KEY) se guarda únicamente como secreto de la Edge Function. El correo remitente de esta pantalla es un dato no secreto.

WhatsApp de Compras

Manual abre el chat; Cloud API permite envío desde el CRM.

El CO_WHATSAPP_TOKEN (o WHATSAPP_TOKEN) no se captura aquí. Déjalo en Supabase Secrets. En modo manual el mensaje sale desde la sesión de WhatsApp abierta en el equipo.

Qué datos necesita el CRM

Proveedor: correo, teléfono/WhatsApp y contacto. Compras: correo remitente, nombre visible, reply-to y número asignado. Para integraciones automáticas solo faltan los secretos privados en Supabase. Así el directorio y los envíos quedan separados de las credenciales sensibles.
