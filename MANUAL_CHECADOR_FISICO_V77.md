# Manual técnico - Checador Wi-Fi Skilled V85

El manual actualizado se incluye en la carpeta `CHECADOR` como:

`Manual_Checador_WiFi_Skilled_V85.pdf`

Incluye dos rutas de implementación:

- Raspberry Pi: opción recomendada para el equipo principal por su facilidad de mantenimiento, interfaz local, SQLite y soporte de periféricos.
- ESP32-S3: alternativa compacta para una terminal dedicada de huella/código con cola local y sincronización Wi-Fi.

El documento explica componentes, cableado, instalación, alta de la terminal en RH, configuración, registro/listado/eliminación de huellas, pruebas sin internet, sincronización, seguridad, solución de problemas y puesta en marcha.

La configuración de producción debe usar un PIN administrativo propio y un token de terminal emitido desde RH.
