CRM SKILLED · V20 · NUEVO FLUJO DE COTIZACIONES
Fecha: 07/08/2026

1. ALMACÉN · BAJO MÍNIMO
- Bajo mínimo ya no obliga a generar una orden de compra.
- Permite seleccionar uno o varios materiales y enviar una solicitud de cotización a Compras.
- La solicitud conserva almacén, existencia, stock mínimo/medio/máximo, cantidad a cotizar, prioridad, fecha requerida, responsable, referencia y notas.
- Un material con cotización abierta queda marcado para evitar solicitudes duplicadas.

2. COMPRAS · COTIZACIONES
- Nueva bandeja CO.cotizaciones.html.
- Lista todos los materiales solicitados por Almacén.
- Carga automáticamente las opciones registradas en el catálogo proveedor-material.
- Compara precio y plazo de entrega material por material.
- Recomendación automática: 65% precio + 35% plazo de entrega.
- Compras puede revisar todas las propuestas y elegir manualmente otra opción.
- Al aprobar la comparación, la propuesta seleccionada queda registrada como relación proveedor-material.

3. PROVEEDORES Y MATERIALES
- Cada proveedor tiene catálogo propio de materiales.
- Permite precio unitario, moneda, plazo de entrega, cantidad mínima, vigencia, última cotización y notas.
- Alta manual de material por proveedor.
- Importación masiva Excel/CSV optimizada por bloques.
- Plantilla Excel descargable.

4. PROVEEDORES TEMPORALES
- Desde una cotización se pueden seleccionar proveedores existentes y agregar proveedores temporales.
- Un proveedor temporal NO se agrega al directorio de manera inmediata.
- Si una oferta temporal es seleccionada y la cotización se aprueba, el proveedor se guarda y también se guarda el material/precio/plazo aceptado.

5. CORREOS Y MENSAJES PREDETERMINADOS
- Cotizaciones incluye plantillas editables de correo.
- Variables: {{folio}}, {{materiales}}, {{fecha_requerida}}, {{referencia}}, {{proveedor}}.
- Se incluyen plantillas iniciales de solicitud, seguimiento y confirmación.
- Cada solicitud queda registrada con estado de envío.
- Si se configura la Edge Function incluida, el correo se envía directamente desde el CRM.
- Si no se configura todavía, se conserva el enlace de envío manual desde el cliente de correo.

6. SQL
- Se mantiene la regla de un único archivo: SQL_MAESTRO_CRM.sql.
- No se generaron SQL independientes.
- V20 agrega co_cotizaciones, co_cotizacion_items, co_cotizacion_ofertas, co_proveedor_materiales y co_plantillas_correo, además de la función segura co_aprobar_cotizacion.

7. CORREO DIRECTO
- Edge Function incluida: supabase/functions/enviar-solicitud-proveedor/index.ts
- Configuración explicada en CONFIGURAR_ENVIO_CORREO_COMPRAS.md.
- Las claves privadas nunca se guardan en el frontend.

8. SKY · COMPRAS
- Sky reconoce el nuevo flujo de cotizaciones dentro del perfil Compras.
- Consultas: cotizaciones por revisar, búsqueda por folio/material, comparación de proveedores, precio y plazo.
- El resumen de Compras incluye las cotizaciones abiertas.

9. SEGURIDAD DE LA COMPARACIÓN
- La recomendación automática solo compara precios cuando las ofertas válidas están en la misma moneda.
- Si existen monedas diferentes, el CRM muestra todas las opciones pero exige selección manual hasta definir una conversión de moneda.
- Las ofertas vencidas no participan en la recomendación automática.
